## 지표 계산과 한계

- 페이지 평균 참여 시간 = userEngagementDuration / activeUsers. GA4의 활성 화면 시간이며, 단순히 탭을 열어 둔 시간이나 개인별 녹화가 아니다. 0명 또는 미조회이면 `—`.
- 유입/기기별 세션당 참여 시간 = userEngagementDuration / sessions. 평균 세션 지속 시간과 구분한다.
- 문의 발생 세션 비율 = generate_lead가 발생한 세션 / 전체 세션. 클릭 수나 CRM 고객 수로 대체하지 않는다.
- CRM 코호트 = 선택 기간에 등록된 비테스트 고객. 보관 고객도 결과에 포함한다. 계약일이 기록된 고객을 계약으로 계산한다. 확정 계약금액은 입금·매출 인식 또는 광고 기여 매출이 아니다.
- Meta CPA는 기존 7일 클릭/1일 조회의 광고 기여 웹사이트 Lead 기준. CRM 매출과 임의 결합한 ROAS는 표시하지 않는다.
- 링크의 위치는 상단 메뉴/하위 메뉴/본문/하단 메뉴/검색 영역 및 링크 순번이다. 동일 목적지의 다른 링크를 구별할 수 있고, 페이지 개편 시 순번이 달라질 수 있다.
- 링크명은 공개 링크 제목/텍스트의 안전한 짧은 값만 사용한다. 이메일/전화번호형 값과 query/hash를 제외한다. 입력값·검색어·관리자 화면은 수집하지 않는다.
- 스크롤은 실제 스크롤 동작이 있고 화면이 보일 때, 페이지 진입별 각 지점을 한 번씩 기록한다. 짧은 페이지는 제외한다. 읽기 완료를 의미하지 않으며 적용 전 조회를 포함한 기간에서는 도달 비율이 낮게 나타날 수 있다.
- GA4 상세 집계는 처리 지연이 있다. 직전 기간의 분모 0/미확인은 증감률을 만들지 않는다. 당일 포함 비교는 잠정 수치다.
- 상세 CSV는 현재 페이지/검색 필터 결과를 내보내며 스프레드시트 수식 실행을 방지한다.
