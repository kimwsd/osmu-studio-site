# Inside OSMU 대체 제안

## 추천: 브랜드가 쓰이는 방식

하나의 완성 로고가 간판·명함·카드·패키지·응용물로 이어지는 과정을 보여준다. Selected Work가 여러 프로젝트를 소개한다면 이 섹션은 한 브랜드의 시각 규칙이 실제 매체에서 유지되는지 보여준다. OSMU의 이름과 서비스 범위를 구체적으로 설명할 수 있다.

- 제목: **One identity. Many expressions.**
- 설명: 하나의 브랜드가 여러 순간에 같은 인상으로 남도록.
- 내용: 기존 원본 로고 1개 + 같은 브랜드의 응용 이미지 5개
- 캡션: 적용 매체와 디자인 판단을 한 문장으로 표시. 예: 종이의 두께와 인쇄 대비로 로고의 작은 선까지 살렸습니다.
- 링크: 프로젝트 전체 보기 → 해당 Work 상세 페이지
- 프로젝트 상태: 실제 고객 작업인지 자체 콘셉트인지 현재 확인된 상태를 표시

## 반응형 구성

- 데스크톱: 한쪽에 원본 로고·짧은 설명, 다른 쪽에 큰 응용 이미지. 아래 5개 매체 탭으로 전환.
- 모바일: 제목 → 원본 로고 → 응용 이미지 → 매체 선택 → 상세 링크 순서. 터치로 선택하며 hover에 의존하지 않음.
- 로고·명함·패키지의 인쇄 그래픽은 전체 영역이 보이도록 원본 비율을 유지. 의미 있는 글자·심볼을 화면 채우기 용도로 자르지 않음.
- CSS에서 로고의 가로·세로를 별개로 늘이지 않음. 설명은 실제 텍스트로 제공하고 좁은 화면에서 자연스럽게 줄바꿈.
- 화려한 자동 전환보다 사용자가 비교할 수 있는 전환을 사용. reduced motion 설정 대응.

## 대안과 선택 이유

서비스 바로가기 7개를 넣으면 원하는 작업으로 빨리 이동할 수 있다. 다만 이미 Services 페이지가 있어, 현재는 실제 응용 이미지를 통해 디자인의 일관성을 보여주는 구성이 더 적합하다.

이 문서는 구성 제안이다. 아직 홈페이지에 새 섹션을 추가하지 않았다. 로고 원본 보존을 검수한 응용물과 대표 브랜드가 정해진 뒤 실제 화면으로 구현한다.
