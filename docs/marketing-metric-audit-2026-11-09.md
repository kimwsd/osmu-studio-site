기준: 2026-11-09 KST. 조회 기간 2026-10-11~2026-11-09. 검증 트래픽은 사업 성과로 해석하지 않는다.

## 발견 및 수정

| 항목 | 문제 | 수정 |
|---|---|---|
| 신규 문의 | inquiries 전체 건수에 CRM 테스트 문의 포함 | 연결된 테스트 문의 ID를 중복 없이 제외, 기간은 KST 반개구간 |
| GA4 방문자·세션 | 일반 보고서 행 없음이 0으로 변환됨 | 값 null 및 처리된 기록 없음 안내, 실시간과 별도 표시 |
| GA4 날짜별 차트 | 빈 응답/조회 범위 밖 날짜도 0으로 채움 | 기록 없음과 기간 밖은 null, 정상 응답 범위 안의 누락 날짜만 0 |
| CRM 코호트 | 요약은 보관 고객 포함, 상세는 제외 | 양쪽 모두 기간 내 유입·테스트 제외·보관 포함 |
| 확정 계약금액 | 계약일 없는 금액도 상세/재무 합산 가능 | 계약일 있는 고객만 확정 계약금액·미수금 기준으로 합산 |
| 조회 기간 | 이전 요청이 늦게 끝나면 최신 기간 상태 덮어쓰기 가능 | 요청 번호로 이전 응답 무시 |
| GA4 데이터 제약 | 표본/임계값/기타 통합/시간대 메타정보 미표시 | 제약 저장·화면 안내, KST 불일치/비정상 수치 거부 |
| Meta 광고 | 응답에 필수 수치가 누락돼도 0으로 취급 | 필수 필드 누락 거부, 정상 빈 집행 응답만 0 허용 |
| CPC 그래프 | 계산 불가 날짜를 0원으로 그릴 수 있음 | null 구간은 선을 끊음 |
| 진입 세션 | 세부 차원 합산에 의존 | GA4 기간 전체 세션 사용 |

## 운영 원본 대조

- 문의 1건, 연결된 테스트 문의 1건, CRM 미연결 문의 0건 → 실문의 0건.
- CRM 테스트 고객 2건(보관), 비테스트 고객 1건(보관), 계약일 기록 0건. 비테스트 코호트 1명 / 계약 0건 / 확정 계약금액 0원. 활성 CRM 고객은 0명이며 전체 코호트와 기준이 다르다.
- GA4 v10 실제 재조회: generalReportAvailable=0, totalUsers/sessions=null, 최근 30분 방문자=1. 조회 메타데이터 19개 모두 Asia/Seoul, 임계값/표본/기타 통합 경고 없음. 일반 보고서에는 처리된 행이 아직 없다.
- Meta 광고 v2 실제 재조회: 선택 기간 집행 행 없음. 광고비/노출/클릭/웹 문의=0, CPC/CTR/CPA=null. 일별 도달을 합산하지 않고 계정 기간 합계 사용.
- 과거 GA4/Meta 검증 이벤트는 제공자 원본에 남는다. CRM 테스트 제외는 해당 원본 이벤트의 삭제를 뜻하지 않는다. 임의 차감하지 않는다.
