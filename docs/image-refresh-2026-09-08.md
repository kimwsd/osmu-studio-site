## Work와 재사용 영역

Work의 8개 공개 자체 스터디에 대표·디테일 이미지 각 2장, 총 16장을 연결했다. 공간 그래픽은 OPEN ROOM, 캠페인 그래픽은 MOVE TOGETHER, 제작 과정은 AFTER 촬영 세트 콘셉트로 구성했다. 각 프로젝트 설명도 이미지의 실제 기획 내용에 맞췄다.

홈 히어로, Work 카드·상세, 홈 에디토리얼, 서비스 상세 7개, Contact와 쇼릴에 새 이미지를 반영했다. 쇼릴은 새 대표 이미지 8개로 구성한 12초 무음 영상이다. 히어로의 기존 슬라이더 구조와 내비게이션은 유지했다.

모든 결과는 AI 생성 콘셉트다. 실제 고객 프로젝트·실물 패키지 제작·광고 집행·현장 촬영 성과로 표시하지 않는다.

## 파일과 생성 방식

- 웹 파일: `public/assets/work-generated/v2/` — 18장, WebP 품질 88, 총 약 2.1MB
- 쇼릴: `public/assets/osmu-concept-reel-v2.mp4` — 1280×720, 30fps, 12초
- 원본 및 프롬프트 보관: `output/imagegen/20260908/`
- `prompts.md`: 이미지별 전체 영어 생성 프롬프트와 generate/reference edit 모드
- `manifest.json`: 원본 경로·참조 이미지·프롬프트 대응표
- 생성 도구: 기본 Image Generation 도구. 1차 대표 이미지 생성 후 참조 편집으로 디테일과 연관 캠페인·AI 장면의 일관성을 유지했다.
- 후처리: WebP 인코딩과 쇼릴 편집. 디자인 요소의 별도 래스터 수정 없음.
