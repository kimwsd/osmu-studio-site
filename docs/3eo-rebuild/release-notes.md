## 화면과 탐색

- OSMU 원본 로고와 Helvetica 계열 글꼴, 흑백 + 라임 강조색.
- About / Services / Solutions / Insights / Resources 메뉴: 넓은 하위 페이지 패널, 각 페이지 설명, 전체 보기 링크, Escape 및 배경 클릭 닫기, 키보드 포커스 복원.
- 모바일은 접이식 메뉴와 두 열 링크 카드. 헤더 불투명도 80%와 블러 유지.
- 홈 서비스 탭: 데스크톱 6열, 중간 폭 3열, 모바일 2열. 가로 스크롤 없이 모든 서비스 표시.
- Higgsfield 직접 API로 히어로 2안 + 서비스 6장 생성. 히어로 1안과 서비스 6장을 게시하고 문제 소개·블로그에도 동일한 시각 체계 적용.
- AI 일러스트는 서비스 설명용이며 실제 직원·고객 프로젝트·실적을 표현하지 않음. 생성 이미지에 로고나 본문을 넣지 않고 원본 로고와 HTML 텍스트를 유지.
- 640 / 1280 / 2048px WebP 및 JPEG 대체 파일. 비율을 유지하며 주요 인물과 내용이 잘리지 않도록 배치.

## 페이지와 검색 구조

Next.js 정적 출력 42개 페이지: 기본 16개, 서비스 6개, 솔루션 6개, 인사이트 글 8개, 인사이트 카테고리 6개.

각 페이지 H1·고유 제목·설명·canonical 및 화면 내용에 맞는 WebPage / Service / BlogPosting / Breadcrumb / FAQ 구조화 데이터. 공개 sitemap은 초안 편집기를 제외한 41개 URL. 운영 도메인은 https://osmu-studio.com/.

이전 탐색 URL 10개는 canonical + HTML 이동 안내로 연결. 이전 콘텐츠 23개는 noindex 안내 페이지 제공. GitHub Pages 정적 호스팅의 HTML 이동이며 HTTP 301 리디렉션은 아님. 내용이 다른 프로젝트와 새 서비스에 동일한 정본을 강제하지 않음.

## 검증

- `npm run build`, `npm run typecheck`, `npm run validate:export`.
- 정적 검사: 42페이지, 공개 URL 41개, 발견한 내부 링크 35개, 이미지·스크립트·스타일 자산 39개, 이전 URL 33개. 오류 0건.
- PC 메뉴 클릭·키보드 열기·Escape·배경 닫기, 하위 링크, 서비스 탭 전환 확인.
- 모바일 메뉴·탭 줄바꿈·이미지 비율·헤더 불투명도 확인. 검사한 화면에서 가로 넘침 없음.
- GitHub Actions에서 동일한 빌드와 출력 검사를 통과한 후 Pages에 게시. 이후 IndexNow 제출.

## 외부 연결 전인 기능

요청대로 외부 계정 연결은 후속 작업으로 남겼음.

- 상담: 복수 선택과 입력 검사까지, 서버·메일·CRM 전송 없음. 화면에 미접수 상태 표시.
- 콘텐츠 편집기: 현재 브라우저에 초안 저장·복원·JSON 내려받기. 관리자 인증·CMS·실제 발행·동기화 없음.
- 분석: GA4/GTM 및 검색 콘솔 미연결. 순위·AI 인용·매출 개선을 측정한 결과가 아님.
- 사례: 공개 승인된 실제 사례가 준비되기 전까지 빈 상태로 안내.

원본 파일과 이전 사이트는 로컬 `.backups/` 및 Git 이력으로 보존. API 키는 사이트·소스·문서·배포 결과에 포함하지 않음.
