- 문의함에서 연락처, 서비스, 문의 내용 조회와 처리 상태 변경. 30건 단위 목록.
- 블록 편집기에 표 셀 편집, 행/열 추가, 참고 링크 지원 추가. 이미지/영상 업로드 및 미리보기.
- 초안과 공개본 분리. 발행/공개 중단 후 CI 배포 완료 시 사이트 반영.
- CI에서 공개본 동기화. 빈 CMS 및 조회 오류 시 빌드 중단하여 이전 사이트 유지.
- cms-deploy는 getUser로 인증과 현재 app_metadata 관리자 권한을 확인. 고정 저장소/워크플로만 실행. publishable key 호환을 위해 게이트웨이 JWT 검사를 끄고 함수 내부에서 인증한다.
- GitHub 발행 키는 사용자 승인 후 Supabase 서버에만 저장. osmu-studio-site 저장소 Actions read/write, 필수 Metadata read-only. 만료일 2027-02-06. 소스/공개 번들에 키 저장 금지.
- GA4/GTM/Meta/CAPI 실제 수집은 다음 단계. 미연결 지표는 0으로 표시하지 않는다.

## 검증
- 로컬 테스트 19개 통과: 콘텐츠 보존, 이미지 검증, 문의 입력/알림 재시도.
- 일반 사용자 권한: 초안 0행, 문의 0행, 공개 글 8행. 익명 REST에서도 초안/문의 차단.
- 관리자 권한 트랜잭션: 초안 변경→공개본 유지→발행→공개 중단→초안 유지 후 rollback. 공개 글 변경 없음.
- 배포 함수 비로그인 요청 401.
- 48개 페이지 빌드 및 메타/구조화 데이터/링크/이미지 검증 통과.
- 실제 관리자 로그인, 초안 저장/새로고침 유지, 이미지 업로드/공개 글 반영, 문의 상태 변경 확인. 발행 workflow_dispatch 42470016720 및 삭제 반영 42473270798 성공.

## 운영 순서
1. /admin/에서 기존 계정으로 로그인.
2. 인사이트 편집→저장: 초안만 저장. 이미지·영상 설명 작성. 공개 파일만 업로드.
3. 미리보기/검색·공유 항목 확인→발행 요청.
4. 사이트 반영 대기→게시 중 확인. 오류 시 공개본과 기존 사이트는 유지. 대시보드에서 사이트 반영 재시도 또는 GitHub Actions 수동 실행.
5. 공개 중단도 배포 완료 확인. 모든 글을 내리는 경우 빈 CMS 보호 때문에 별도 운영 검토 필요.
6. 키 만료 전 교체. 관리자 권한 회수 시 기존 세션도 종료.
7. 복구는 Git에 남은 cms-snapshot 또는 콘텐츠 백업과 대조하여 초안을 복구하고 재발행. 과거 CI만 다시 실행하면 최신 CMS가 다시 반영됨에 유의.

기존 Supabase 유출 비밀번호 차단 경고는 별도 계정 보안 설정 검토 대상:
https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection

## 2026-11-08 후속 수정
- 로컬 관리자에서 로컬 cms-release.json을 읽어 발행 완료를 대기로 표시하던 원인 수정. 운영 도메인의 배포 기록을 조회하며 조회 실패는 별도 표시한다.
- 인사이트: 글 편집 > 발행 설정 > 삭제 · 휴지통으로 이동. 인사이트 목록 > 휴지통 > 글 선택 > 초안으로 복구. 복구는 재발행하지 않는다.
- 미디어: 파일별 삭제 > 휴지통 이동 및 복구. 원본과 URL은 보관하며 저장 용량을 비우는 영구 삭제가 아니다. 초안/공개본/휴지통 글에서 사용하는 파일은 삭제 제한. 공개 중인 이미지의 손실 방지.
- 관리자 메뉴/글 편집을 브라우저 방문 기록과 연결. 내부 목록 버튼과 뒤로가기에서 계속 작성/저장하지 않고 이동/저장 후 이동 제공.
- DB 검증: 관리자 글 복구는 초안만 복구, 휴지통 글 재발행 차단. 비관리자 글 삭제와 미디어 휴지통 쓰기 차단. 미디어 휴지통/복구 트랜잭션 검사 후 rollback.
- 화면 검증: 메뉴 뒤로가기/앞으로가기, 미저장 편집 이동 취소 시 내용 보존, 저장하지 않고 이동, 사용 중 미디어 삭제 제한 확인.
- 공개 글 8개 보존. 48개 페이지(색인 대상 47), 로컬 링크 251개, 리소스 47개, 구형 이동 18개, 종료 URL 58개 검증 통과.
