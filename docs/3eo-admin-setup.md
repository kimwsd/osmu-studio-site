# 3EO 관리자 · 연결 보류 현황

2026-11-07. 사용자가 Supabase와 측정 도구 연결을 나중에 설정하도록 요청했습니다.

## 현재 사용 가능
- `/admin/`: 공개된 인사이트로 구성한 대시보드 미리보기. 민감한 관리자 데이터는 읽지 않습니다.
- 인사이트 목록, 검색, 블록 편집·미리보기(문단/제목/목록/인용/이미지/영상), SEO·공유 설정 UI.
- UTM URL 생성·복사. 영구 저장은 연결 후 이용합니다.
- 미디어 라이브러리, GA4·GTM·Meta Pixel·CAPI 연결 설정 UI.
- 서비스: 3EO 검색 최적화(SEO/AEO/GEO 통합), 마케팅 컨설팅, 웹사이트, 콘텐츠, 퍼포먼스, 데이터.
- 인사이트별 OG/Twitter 이미지, BlogPosting, BreadcrumbList, canonical과 사이트맵.

## 보류 — 현재 동작하지 않음
- 관리자 인증 및 초안 저장/발행/공개 중단, 이미지·영상 업로드.
- Supabase 테이블·저장공간 추가. 기존 데이터/권한을 변경하지 않았습니다.
- 발행 후 GitHub Pages 자동 갱신. 주기 실행이나 새 자동화는 설치하지 않았습니다.
- GA4 보고서 수집, GTM·픽셀 태그 실행, 동의 UI, Meta CAPI 서버 전송.
- 실제 분석 수치/인용/순위는 측정하지 않았습니다. 미연결 값은 0으로 표시하지 않습니다.

## 연결할 때 확인할 순서
1. 기존 관리자 권한과 스키마를 재확인하고 `supabase/cms-schema.sql`을 검토 후 적용합니다. 이 파일은 현재 미실행 설계안입니다.
2. 기존 공개 글을 CMS로 가져옵니다. 빈 테이블을 동기화하면 기존 글이 사라지므로 초기 콘텐츠 이관을 먼저 합니다.
3. 별도 테스트 계정으로 비관리자 접근 차단, 초안 비공개, 공개본 유지, 업로드 권한/실패/중복 등을 검증합니다.
4. `lib/cms-public.json`의 ready를 켜기 전에 발행/배포 연계를 설치합니다. 공개 키만 사용하며 서비스 역할 키는 브라우저에 넣지 않습니다.
5. `npm run cms:sync`는 공개 스냅샷을 가져오는 준비된 빌드 도구입니다. 현재 ready:false여서 네트워크 호출 없이 종료합니다. 새 글, 수정, 공개 중단, 배포 실패 복구를 스테이징에서 검증한 뒤 CI에 연결합니다.
6. GA4/GTM/Meta 식별자, 실제 전환 정의와 동의 범위를 확정합니다. API 자격증명과 CAPI 토큰은 서버 보안 저장소에서만 관리합니다.
7. 태그 설치와 보고서 수집은 구분합니다. CAPI는 접수 성공 후 전송과 Pixel event_id 중복 제거를 확인합니다.

관리자 미리보기에서 편집한 내용은 보관되지 않습니다. 실제 저장·발행이 필요한 시점에 연결과 검증을 진행합니다.
