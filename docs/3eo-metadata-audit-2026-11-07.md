# 3EO 메타정보·구조화 데이터 점검

점검일: 2026-11-07. 운영 도메인의 사이트맵에 있는 공개 41개 URL과 수정한 정적 HTML을 비교했습니다.

| 항목 | 변경 전 운영 사이트 | 수정 빌드 |
|---|---|---|
| 공개 페이지 HTTP 접근 | 41/41 정상 | 41개 HTML 생성 |
| 페이지별 제목·설명·canonical·H1 | 41/41 존재 | 41/41 확인, 중복 없음 |
| JSON-LD 문법 | 41/41 파싱 가능 | 41/41 파싱 가능 |
| 인사이트 JSON-LD 이미지 | 서로 다른 6개 주소가 404 | 실제 editorial 이미지 주소로 변경, 파일 확인 |
| 인사이트 OG/Twitter 이미지 | 8개 글 모두 공통 로고 | 각 글 대표 이미지 적용 |
| 공유 기본 이미지 | 로고 이미지 200 | 홈페이지·일반 페이지에서 유지 |
| 관리자 | 로컬 초안 편집기 | /admin/ 대시보드 미리보기, noindex/nofollow, 사이트맵 제외 |
| 서비스 | SEO와 AEO·GEO 별도 | 3EO 통합 + 마케팅 컨설팅 |

BlogPosting 이미지 주소와 OG 이미지가 실제 화면의 대표 이미지와 연결되도록 수정했습니다. 작성·수정 날짜는 ISO 형식이며, FAQPage는 화면의 동일 질문·답변 배열로 생성합니다. Organization과 WebSite의 식별자 연결도 보완했습니다.

서비스 구형 주소 `/services/seo/`, `/services/aeo-geo/`는 `/services/3eo/`로 안내합니다. GitHub Pages 환경의 HTML 이동 처리로, HTTP 301 리다이렉트는 아닙니다.

검증 범위: 빌드, 타입 검사, 42개 페이지(관리자 포함)의 메타·H1·정규 URL·내부 링크·로컬 이미지, JSON-LD 파싱, 미디어 URL 입력 검증, PC/모바일 메뉴·관리자 편집·미리보기·UTM 생성. Google 리치 결과 도구 전체 판정이나 실제 검색 색인/노출/AI 인용 성과를 검증한 결과는 아닙니다.

Supabase 저장·업로드·발행 및 측정 연결은 사용자 요청으로 보류했습니다. 구현과 운영 데이터 연결 상태는 `3eo-admin-setup.md`에 구분했습니다.
