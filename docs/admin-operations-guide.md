# 관리자 운영 기능 안내

사용 주소: https://osmu-studio.com/admin/

## 일상 업무 순서

1. **대시보드 → 연락 · 할 일**: 고객을 고르고 연락할 내용, 담당자, 예정일을 등록합니다. 완료한 일은 완료 목록에 남고 다시 열 수 있습니다. 날짜를 수정하고 다른 곳을 누르면 예정일이 저장됩니다.
2. **고객 · CRM**: 실제 첫 연락 후 첫 응답 시각을 표시하고, 상담 적합 여부와 보류·종료 사유를 기록합니다. 계약금액과 계약일은 고객 정보 저장으로 확정합니다.
3. **고객 상세 → 입금 내역**: 실제 확인한 계약금·잔금·기타 입금만 등록합니다. 잘못 기록한 입금은 취소 후 복원할 수 있습니다. 예상 금액과 실제 입금은 별개로 집계합니다.
4. **유입 · 계약 성과**: 선택한 기간에 들어온 고객이 현재까지 계약으로 이어진 비율을 확인합니다. 동의 후 문의에 첨부된 UTM·첫 방문·마지막 인사이트 경로만 사용합니다. 경로 미확인을 직접 유입이나 0으로 바꾸지 않습니다.
5. **인사이트**: 편집을 멈추고 2초 후 서버에 초안이 저장됩니다. 제목을 지워도 초안으로 저장할 수 있지만 발행에는 필수 항목이 필요합니다. 다른 창의 변경과 충돌하면 저장을 중단합니다. 이전 버전 복원은 초안에만 적용됩니다.
6. **예약 발행 · 발행 일정**: 한국 시간으로 1분 이후부터 예약합니다. 저장된 버전만 예약 시각에 발행되며, 그 뒤 수정·삭제하면 확인 필요 상태가 됩니다. 수정 후에는 다시 예약하세요. 서버가 1분마다 확인하고 GitHub 배포가 이어지므로 실제 공개에는 몇 분 더 걸립니다.
7. **운영 · 백업**: 문의 알림 오류, 최근 배포 기록과 예약 오류를 확인합니다. 재시도는 기존 관리자 알림과 기존 사이트 배포만 실행합니다. 고객에게 메시지를 보내지 않습니다.

## 백업과 복원 범위

- 매일 한국 시간 오전 3시 10분에 비공개 데이터 백업을 생성합니다. 지금 백업과 JSON 다운로드도 가능합니다.
- 글·공개본, 고객·할 일·입금·상담 기록, 문의·UTM을 보관합니다. 이미지·영상은 파일 자체 대신 참조 주소가 들어 있습니다.
- 복원 미리보기는 누락된 글·고객·할 일·입금을 셉니다. 확인 후 복원해도 기존 레코드나 공개 사이트를 덮어쓰지 않습니다. 복원된 글은 초안입니다.
- 백업에는 고객 정보가 들어갈 수 있으므로 관리자 전용 보관 위치를 사용하세요. 자동 삭제는 설정하지 않았습니다. 문의 삭제·보관 기간 정리 시 관련 백업과 내려받은 사본을 함께 관리해야 합니다.

## 다음에 연결할 항목

GA4, GTM, Meta Pixel, CAPI와 외부 광고 보고서는 이번 작업에서 연결하지 않았습니다. 방문자·세션·광고비·클릭 등의 실제 수치는 연결 후 제공됩니다. 검색·AI 노출 기록은 추가하지 않았습니다.
