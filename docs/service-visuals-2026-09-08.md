# 서비스 이미지 교체 기록 — 2026-09-08

7개 서비스 상세 페이지에서 제공 내용과 이미지의 관계를 구체화했다.

| 서비스 | 이미지와 근거 |
|---|---|
| 브랜드 진단·컨설팅 | 현황 진단 → 포지셔닝 방향 → 실행 우선순위의 산출물 구성 예시. 실적 수치 없는 네이티브 그래픽. |
| 브랜딩 | 사용자 제공 Atelier Veld 원본 로고 + 서체·색상 역할·명함·가이드 표지. 로고 원본 바이트를 그대로 임베드한 시각 체계 콘셉트. |
| 그래픽 디자인 | 사용자 제공 Buterra 로고를 보존한 패키지 응용 콘셉트. 로고 없는 생성 배경과 원본 로고 레이어를 분리해 제작. |
| 사진·영상 | 사용자가 유지하기 원한 AFTER 향수 콘셉트 스틸을 그대로 사용. |
| 마케팅 | 기존 AFTER 원본 이미지를 캠페인 키비주얼·피드·숏폼 표지·주간 운영안으로 전개. 성과 수치 및 미확인 고객 정보 없음. |
| 웹·디지털 | 실제 OSMU Services 페이지의 PC·모바일 화면을 원래 비율로 배치. |
| AI 이미지·영상 | 기존 AFTER 기준 제품 비주얼과 AI 확장 장면을 별도 이미지·라벨로 비교. 자체 콘셉트 예시이며 실제 제작 실적으로 표시하지 않음. |

## 구현

- `lib/service-visuals.ts`에서 서비스 slug별 원본 크기, 설명, 콘셉트 표시 관리.
- 원본 이미지 클릭 시 큰 파일로 열기. 임의 크롭·비율 왜곡 없음.
- 캡션은 실제 HTML 텍스트이며, 모바일에서 줄바꿈하고 한 열로 전환.
- 이미지 가장자리에 소폭 라운딩 유지.
- 구형 `/services/packaging/` 별칭을 실제 패키지 제공 서비스인 Graphic Design에 연결하고 정본도 일치시킴.
- 배포 이미지 5개는 PNG 원본에서 무손실 WebP로 인코딩. 원본 제작 파일과 로고 소스는 로컬 작업 폴더에 보존.

## 검증

- 정적 빌드 및 타입 검사 성공.
- 1440px에서 7개 상세 페이지 이미지 로딩, 비율, 가로 넘침 확인.
- 320px·390px에서 7개 상세 페이지 모두 이미지 로딩 성공, 가로 넘침 없음. 표시 비율 오차는 픽셀 반올림 범위 내.
- 별도 검수에서 7개 서비스 연결, 원본 크기, 콘셉트 표시, 개인정보·허위성과 없는 구성 확인.
- 기존 내비게이션의 80% 배경과 표준 `backdrop-filter` 회귀 검사 유지.

전체 Work 포트폴리오를 교체한 변경은 아니다. 브랜드 응용물 제작은 별도 로컬 폴더에서 계속 관리한다.
